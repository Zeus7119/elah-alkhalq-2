# 🌌 إله الخلق — لعبة الإله المطلق

لعبة 2D باللغة العربية: أنت إله مطلق القوة بموارد غير محدودة، تخلق النجوم والكواكب
والثقوب السوداء والمجرّات وأنظمة شمسية كاملة، وتخلق الحياة (إنسان، نبات، حيوان، سمكة)
وعناصر الطبيعة (ماء، تربة، جبال) — كل ذلك بلا أي حدود.

## ⚔️ حروب العوالم

في الوجود آلهة آخرون لهم عوالمهم الخاصة. يمكنك إعلان **حرب عوالم** على أي منهم:

1. **معركة العوالم**: مخلوقات العالَمين تقاتل في 4 جولات.
2. **نزال الآلهة**: بعد انتهاء معركة العوالم يبدأ النزال الفردي بين الإلهين —
   لعبة توقيت (اضغط «اضرب الآن» عندما يكون المؤشر في المنطقة الخضراء، أفضل من 3 جولات).

**النتيجة**: الفائز يزداد قوةً، ويحوز عوالم الإله المهزوم، ويصبح مصير المهزوم
قوةً تغذي الفائز. الآلهة الاصطناعيون يحاربون بعضهم بعضاً أيضاً!

## 🎮 التحكم

- اختر عنصراً من **لوحة الخلق** ثم انقر في الفضاء للخلق.
- **عجلة الفأرة**: تقريب/إبعاد — **الزر الأيمن أو الأوسط (سحب)**: تحريك الكاميرا.
- **WASD / الأسهم**: تحريك الكاميرا.

## 🚀 البناء كـ APK عبر GitHub (بدون أي برامج على جهازك)

1. أنشئ مستودعاً جديداً على GitHub وارفع كل ملفات هذا المشروع إليه.
2. اذهب إلى تبويب **Actions** — ستبدأ عملية البناء تلقائياً (أو اضغط *Run workflow*).
3. بعد دقائق، افتح آخر عملية بناء ناجحة ومن قسم **Artifacts** حمّل
   `Elah-AlKhalq-APK` وستجد ملف `elah-alkhalq.apk` — انقله لهاتفك وثبّته.

> ملاحظة: ملف APK الناتج موقّع بمفتاح تصحيح (debug) مناسب للتثبيت المباشر.
> للنشر على Google Play يجب لاحقاً إنشاء keystore إصدار (release) ووضع بياناته
> في `export_presets.cfg`.



## ✨ الميزات الجديدة

### 💾 حفظ التقدم
- زرّا **«حفظ»** و**«تحميل»** في لوحة الخلق يحفظان كل شيء: قوّتك وشدّتك وأسماء الآلهة
  وكل الأجرام الكونية (مواقعها وألوانها ومداراتها وأعداد مخلوقاتها).
- **حفظ تلقائي** كل 30 ثانية، وبعد كل حرب — لا تخسر كونك أبداً.
- ملفات الحفظ تُخزَّن على جهازك في مساحة اللعبة الخاصة (`user://`).

### 🔊 مؤثرات صوتية
- أصوات مولّدة برمجياً بالكامل (لا ملفات صوتية): صوت الخلق، ضربات النزال، نغمة
  الانتصار، ونغمة الهزيمة — تعمل فوراً على أندرويد دون أي إعداد.

### ✏️ تخصيص أسماء الآلهة
- في لوحة الخلق، قسم «أسماء الآلهة» يتيح لك تسمية نفسك وتسمية الآلهة الثلاثة
  كما تشاء — الأسماء تظهر في سجل الأحداث وحروب العوالم وتُحفَظ مع تقدّمك.

## 🛠️ التقنيات

- المحرك: **Godot 4.3** (لغة GDScript) — رسوميات 2D، حجم APK صغير.
- الخط: Noto Sans Arabic مضمّن داخل اللعبة (يدعم التشكيل والاتجاه RTL).
- البناء الآلي: GitHub Actions باستخدام صورة `barichello/godot-ci`.

## 📁 بنية المشروع

- `scripts/main.gd` — إدارة اللعبة، الخلق، الحروب، الواجهة العربية.
- `scripts/body.gd` — الأجرام الكونية (نجوم، كواكب، مخلوقات...).
- `scripts/god.gd` — فئة الإله (اللاعب والآلهة الاصطناعيون).
- `scripts/sfx.gd` — توليد المؤثرات الصوتية برمجياً.
- `.github/workflows/build.yml` — بناء APK تلقائياً.
